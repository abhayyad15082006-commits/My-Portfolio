# Abhay Yadav — Personal Portfolio (2026)

A modern, dark-themed personal portfolio website built with clean HTML5, custom CSS, and 
fluid GSAP animations. Designed with a bold, editorial aesthetic to highlight software 
engineering projects, web development experience, and competitive programming achievements.

---

## ✨ Key Features

- **Preloader Animation:** Custom loading overlay with progress indicator and entrance typography setup.
- **Custom Cursor & Smooth Interactivity:** Interactive cursor follow-effect on desktop with hover scaling over interactive links.
- **GSAP & ScrollTrigger Animations:** Timeline-driven hero animations, smooth reveal effects on scroll, and title line masking.
- **Selected Works Showcase:** Minimalist typography layout featuring interactive hover previews and direct project links.
- **Fully Responsive:** Optimized layouts across mobile, tablet, and desktop viewports using CSS Grid/Flexbox and dynamic dynamic typography (`clamp()`).

---

## 🛠️ Tech Stack & Libraries

- **Markup:** [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) (Semantic elements, Accessibility standard attributes)
- **Styling:** [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) (Variables, Flexbox, Grid, Custom Keyframes)
- **Typography:** [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) & [DM Mono](https://fonts.google.com/specimen/DM+Mono) via Google Fonts
- **Animations:** [GSAP 3](https://greensock.com/gsap/) with [ScrollTrigger](https://greensock.com/scrolltrigger/) plugin
